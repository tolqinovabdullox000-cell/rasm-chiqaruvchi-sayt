# 🖼️ Rasm Galereyasi

Foydalanuvchi o'z kompyuteridan rasm tanlab, chiroyli galereya ko'rinishida ko'rish imkoniga ega bo'lgan sayt. Loyiha toza **HTML, CSS va JavaScript** asosida yaratilgan, hech qanday framework ishlatilmagan.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## 🚀 Xususiyatlari

- ➕ **Qo'shish tugmasi** — bosilganda fayl tanlash oynasi ochiladi va kompyuterdan rasm tanlanadi
- 🖼️ **Galereya qatori** — tanlangan rasmlar pastda qator (thumbnail) shaklida chiqadi
- 🔍 **Katta ko'rinish** — qatordagi istalgan rasmni bosilsa, u katta ekranda ochiladi
- 🗑️ **O'chirish** — yuqoridagi qatordan istalgan rasmni olib tashlash mumkin
